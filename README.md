# Day 5 - Condition Practice

Today I practiced decision-making in C++ using conditions
and logical operators.

## Topics Learned
- if
- else
- else if
- && (AND)
- Comparison operators
- % (remainder operator)

## Practice Programs
- Even / Odd Checker
- Positive / Negative / Zero Checker
- Larger Number Checker
- Largest of Three Numbers
- Voting Eligibility Checker
- Student Eligibility Checker

## Key Learning

`&&` means both conditions must be true.

Example:

`age >= 18 && marks >= 60`

## Important Learning

`else` runs when all previous conditions are false.
